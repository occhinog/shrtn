shrtn.link

Link brevi, senza backend.

Un accorciatore di URL completamente statico. Ogni link è una riga in un file JSON versionato su Git: nessun database, nessun pannello di controllo, nessun tracking.

Come funziona

https://shrtn.link/instagram
   ↓
https://instagram.com/smartai_it

Aggiungi /qr a qualsiasi link per ottenere il QR code scaricabile: shrtn.link/instagram/qr

Caratteristiche

  • Nessun tracciamento, nessun cookie, nessuna analitica.
  • Anteprime Open Graph corrette su LinkedIn, WhatsApp e Instagram.
  • QR code generato al volo per ogni link, scaricabile in PNG.
  • Controllo automatico settimanale delle destinazioni non più raggiungibili.

Aggiungere un link

I link vivono in links.json nel repository. Una pull request, la validazione automatica passa, il link è online.
